Business Intelligence·Concept

Olist Sales Analysis

Analysis of Olist e-commerce data on monthly revenue trends and the product categories that contribute the most, delivered through a PostgreSQL database and a Metabase dashboard.

Problem
Understand monthly revenue trends and which product categories contribute the most on a Brazilian e-commerce marketplace.
Solution
Built a PostgreSQL database from nine tables with a versioned schema (Alembic), analyzed it with SQL (CTEs and window functions), and presented the results in a Metabase dashboard.
Impact
Showed that 2018 revenue growth (+138.3%) was driven by order volume, not price, and that the November 2017 spike coincided with Black Friday, supporting promotion planning and category focus.
SQL / PostgreSQL / Alembic / Metabase

Data Analytics·Concept

Online Retail Customer Analysis

Customer analysis of a UK online store using RFM segmentation and cohort retention to find high-value, at-risk, and returning customers.

Problem
Identify the most valuable customers, those at risk of churning, and how many new customers come back to buy again at a UK online store.
Solution
Cleaned 1M+ transaction rows using documented rules, then ran RFM segmentation and cohort retention analysis in Python (pandas) and Tableau Public.
Impact
Mapped 6 customer segments and found that 14.8% of customers generate 61.3% of revenue, while 709 at-risk customers hold £1.52M in historical revenue, enabling more targeted retention and win-back campaigns.
Python / pandas / Tableau Public

Data Visualization·Concept

Manufacturing Financial Analysis Dashboard

An interactive BI dashboard that turns PT Indocement's static quarterly financial reports into trend analysis by year and quarter, with user roles and an approval workflow for data changes.

Problem
PT Indocement's quarterly financial reports are static PDFs with no period filter or cross period trends, so investors have to compare documents across quarters manually.
Solution
Designed an interactive BI dashboard with Flask, MySQL, and Chart.js (the first version used Metabase), covering operating cash flow, FCF, margin, ROA, ROE, and DER from quarterly data for 2016 to 2025. Added access control by user role (JWT) and an approval workflow for data changes.
Impact
Turned 10 years of static financial reports into interactive trend analysis by year and quarter, and kept data accountable through an approval flow. All 25 Blackbox Testing scenarios passed validation.
Flask / MySQL / Chart.js / JWT
